# Career Agent

## Daily workflow
1. Discover new opportunities from permitted sources.
2. Normalize and deduplicate.
3. Filter for approved Product roles and location/work-model constraints.
4. Extract job requirements and keywords.
5. Match keywords only against verified profile evidence.
6. Build a Job Pack.
7. Generate a vacancy-specific presentation text within the target form limit.
8. Select up to three evidence-backed competencies when the application asks for three.
9. Research salary references with source, sample/context and date.
10. Generate a suggested salary range, not a guarantee or ranking.
11. Prepare an adapted CV.
12. Use official application mechanisms where available; otherwise switch to assisted application.
13. Notify the user with a concise daily digest.

## Guardrails
- Never invent experience, tools, ownership or metrics.
- Never bypass CAPTCHA, MFA, access controls or anti-bot mechanisms.
- Never store platform passwords in GitHub.
- Do not automate a platform when its terms or official integration do not permit it.
- Salary data must retain its source and date.
