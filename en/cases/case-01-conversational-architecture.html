Case 01 · MarIA · Discovery Artifact

Conversational Architecture

Intent organization, dialogue structure and proposed assistant flow guidelines.

Document status: Retrospective documentation based on the available case materials. Language: English.

01 · Intent structure

The interaction model is organized into three central groups: normative queries, procedural support and ticket routing. This separation is intended to avoid treating every question in the same way.

02 · Main interaction flow

1. Receive the employee's natural-language question. 2. Classify the request as normative, procedural or ticket-related. 3. Ask for clarification when intent is ambiguous. 4. Consult only approved official manuals and references. 5. Provide a supported answer or route the request to the appropriate human channel.

03 · Exception handling

When intent is not recognized, ask the user to rephrase or offer objective menu options. When the question is ambiguous, request additional context. When an official source is missing or insufficient, state the limitation and route the user to a responsible human channel. Requests outside the automated scope must not be presented as resolved.

04 · Conversation governance

Approved official manuals and regulations are the permitted reference base. The assistant should recognize uncertainty, avoid inventing rules or procedures and preserve human support when the available content is insufficient.

05 · Evidence note

This is a proposed behavioral architecture derived from the Discovery artifacts. It does not establish a deployed NLP classifier, technical integration or proven operational process.
